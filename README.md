# LeiloesTDSat

## 📌 Sobre o projeto

O LeiloesTDSat é um sistema desenvolvido em Java para gerenciamento de leilões. O projeto permite cadastrar e gerenciar informações relacionadas aos leilões de forma simples e organizada.

## 💻 Tecnologias utilizadas

- Java
- NetBeans
- MySQL
- Git e GitHub

## ⚙️ Funcionalidades

- Cadastro de informações
- Consulta de dados
- Alteração de registros
- Exclusão de registros
- Gerenciamento dos dados do sistema

## 📂 Estrutura do projeto

- `src` — código-fonte do sistema
- `lib` — bibliotecas utilizadas
- `nbproject` — configurações do projeto NetBeans
- `build.xml` — arquivo de configuração de compilação

## 🚀 Como executar

1. Baixe ou clone o projeto.
2. Abra o projeto no NetBeans.
3. Configure o banco de dados, caso necessário.
4. Execute o projeto pela IDE.
